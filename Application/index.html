4. Publisher & Venue Guides
► Add Your Events (Schema.org JSON-LD)

AgendaWeb automatically scans venue sites for standard Google SEO structured data. Paste this in your gig page <head>:

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "MusicEvent", "name": "The Echoes — Album Launch", "startDate": "2026-10-24T20:00:00+11:00", "location": { "@type": "Place", "name": "The Gasometer Hotel", "address": "484 Smith St, Collingwood VIC" }, "offers": { "url": "https://oztix.com.au" }, "image": "https://example.com/poster.jpg" } </script>
► Create an Event RSS Feed (Future Standard)

Publish an open RSS 2.0 feed with the Event module (xmlns:ev) and image enclosure:

<rss version="2.0" xmlns:ev="http://purl.org/rss/1.0/modules/event/"> <channel> <title>Your Venue Gigs</title> <item> <title>Gig Title</title> <ev:startdate>2026-10-24T20:00:00+11:00</ev:startdate> <ev:location>Venue Name, Address</ev:location> <enclosure url="https://example.com/poster.jpg" type="image/jpeg" /> </item> </channel> </rss>
► Embed AgendaWeb Widget (widget.js)

Display your upcoming live gigs on your own website automatically:

<div class="agendaweb-widget" data-venue="your-venue-slug" data-limit="5"></div> <script src="https://agendaweb.app/widget.js" async></script>
