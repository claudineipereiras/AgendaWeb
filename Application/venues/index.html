How AgendaWeb Syndication Works

How does AgendaWeb scrape our gig dates?
AgendaWeb reads standard Schema.org/Event JSON-LD tags embedded directly in your webpage HTML. Most ticketing platforms (Humanitix, Oztix, Eventbrite) and WordPress event plugins automatically render these tags for Google Event Search.
Do we need to log in to keep our dates updated?
No. AgendaWeb is built on open-web principles. Your website is the single source of truth. Whenever you announce a new gig or change set times on your own website, our crawler detects and updates it on AgendaWeb automatically.
Are there any platform fees or commissions?
Zero. AgendaWeb is a community-first, non-commercial cultural feed designed to support Melbourne's grassroots live music, zines, and independent arts.

1. Add Your Events (Schema.org JSON-LD)

Recommended Standard

Schema.org JSON-LD is the official structured data standard recognized by Google Search, Apple, and open web crawlers. Adding this snippet to your gig page ensures AgendaWeb and search engines automatically understand your artist lineups, dates, venue location, and ticket links.

Where to Place This in Common Website Builders

WordPress / WooCommerce If using The Events Calendar or EventON, this is already active! For custom themes, paste into your header.php or event template.
Squarespace Open your event page → Settings → Advanced → paste in Page Header Code Injection.
Wix Go to Settings → Custom Code → add snippet to Head on your Events page.
Custom HTML / Jamstack Paste inside the <head> or right before </body> of your event HTML page.

2. Create an Event RSS Feed (Future Standard)

Open Syndication

RSS feeds aren't just for news! With the standard Event extension (xmlns:ev="http://purl.org/rss/1.0/modules/event/") and poster enclosures, your venue can broadcast an open syndication stream that any reader or festival guide can subscribe to without platform lock-in.

XML feed.xml (RSS 2.0 with ev: module) 
<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:ev="http://purl.org/rss/1.0/modules/event/">
  <channel>
    <title>The Gasometer Hotel — Live Gigs</title>
    <link>https://www.thegasometerhotel.com.au/gigs</link>
    <description>Official live music listings, album launches, and residencies.</description>
    <language>en-au</language>
    
    <item>
      <title>The Echoes — Album Launch</title>
      <link>https://www.thegasometerhotel.com.au/gigs/the-echoes</link>
      <ev:startdate>2026-10-24T20:00:00+11:00</ev:startdate>
      <ev:enddate>2026-10-24T23:30:00+11:00</ev:enddate>
      <ev:location>484 Smith St, Collingwood VIC 3066</ev:location>
      <category>Live Music</category>
      <description>Indie rock outfit celebrating their debut LP release with special guests.</description>
      <enclosure url="https://example.com/posters/the-echoes.jpg" type="image/jpeg" length="124500" />
    </item>
  </channel>
</rss>

3. Embed AgendaWeb Widget (widget.js)

Zero-Maintenance Embed

Want to display your upcoming verified gigs on your own venue website without building a custom backend? Add two lines of HTML to embed a clean, mobile-responsive broadsheet gig guide that updates automatically.

HTML Embed Snippet 
<!-- 1. Target Container (Replace data-venue with your venue slug) -->
<div class="agendaweb-widget" data-venue="the-gasometer-hotel" data-limit="5"></div>

<!-- 2. Lightweight Embed Script (Loads asynchronously) -->
<script src="https://agendaweb.app/widget.js" async></script>
