How AgendaWeb Syndication Works

How does AgendaWeb scrape our gig dates?
AgendaWeb reads standard Schema.org/Event JSON-LD tags embedded directly in your webpage HTML. Most ticketing platforms (Humanitix, Oztix, Eventbrite) and CMS plugins automatically render these tags for Google Event Search.
Do we need to create an account or log in to update dates?
No. AgendaWeb is built on open-web principles. Your website is the single source of truth. Whenever you announce a new gig or change set times on your own website, our crawler detects and updates it on AgendaWeb automatically.
Example Schema.org Event JSON-LD Snippet
If you hand-code your website or manage custom themes, add this snippet to your gig page: 
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "MusicEvent",
  "name": "The Echoes — Album Launch",
  "startDate": "2026-10-24T20:00:00+11:00",
  "endDate": "2026-10-24T23:30:00+11:00",
  "location": {
    "@type": "Place",
    "name": "The Gasometer Hotel",
    "address": "484 Smith St, Collingwood VIC 3066"
  },
  "offers": {
    "@type": "Offer",
    "url": "https://oztix.com.au/event/12345"
  }
}
</script>
Are there any platform fees or commissions?
Zero. AgendaWeb is a community-first, non-commercial cultural feed designed to support Melbourne's grassroots live music, zines, and independent arts.
