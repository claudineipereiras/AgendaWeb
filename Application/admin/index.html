Hostinger Ingestion Worker Setup

The ingestion worker scans all enabled RSS/Atom and Schema.org event sources and updates Hostinger MySQL 8.x.

Hostinger cPanel Cron Command (runs every 30 mins):

php -q /home/YOUR_CPANEL_USER/public_html/sync_sources.php > /dev/null 2>&1
